# Dragon Amulet

A 2D sandbox adventure by Kinard Sproles. Play it here: **https://pumped60.github.io/dragon-amulet-play/**

The wiki is its own app: **https://pumped60.github.io/dragon-amulet-wiki/**

## On a Mac or Windows computer
- **Install from the browser (updates itself):** open the address above in Chrome or Edge and press **Install on this computer** on the title screen (or the install icon at the right of the address bar). It gets its own window and icon and works offline.
- **Download the app:** get the newest version from **[Releases](https://github.com/pumped60/dragon-amulet-play/releases/latest)**.
  - Mac: download the `.dmg`, open it and drag Dragon Amulet into Applications. The first time, right-click the app and choose **Open** (it is not signed by Apple yet).
  - Windows: download `Dragon-Amulet-Setup` (installs with a Start menu icon) or the `portable.exe` (runs without installing). If SmartScreen warns, choose **More info**, then **Run anyway**.
  - F11 switches full screen. Download it again to get a newer version.

## On a phone
- iPhone: open the address in Safari, tap ••• → Share → Add to Home Screen, then start the game from the new icon for full screen.
- Android: open it in Chrome and choose Install app.

Saves stay on the device you play on.
