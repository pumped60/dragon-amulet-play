# Dragon Amulet

A 2D sandbox adventure by Kinard Sproles. Play it here: **https://pumped60.github.io/dragon-amulet-play/**

On iPhone: open that address in Safari, tap ••• → Share → Add to Home Screen, then start the game from the new icon for full screen.

This repository holds only the built game file. Saves stay in the browser on your device.
